## ミッション / ビジョン

Isami Innovations 合同会社は、ソフトウェア技術を通じて価値あるイノベーションを創出し、  
お客様の課題解決と事業成長を支援することを使命としています。

---

## 事業内容

当社は、以下の事業を展開しています。

- コンピュータソフトウェアの企画・研究
- ソフトウェアの開発・設計・製造
- ソフトウェアの販売・保守
- ソフトウェアのリース・賃貸
- ソフトウェアおよび関連技術の輸出入
- 上記に関連するコンサルティング業務
- その他、上記事業に附帯または関連する一切の業務
